# Semantic Inbox Frontend

React + Vite frontend for an AI-enhanced intelligent inbox dashboard. It focuses on UI, architecture, and AI-ready integration points instead of real email delivery.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- ShadCN-style reusable UI primitives
- React Router
- Axios
- Zustand

## Pages

- Login
- Register
- Dashboard
- Inbox
- Email Details
- Search Results
- Settings

## Run

```bash
npm install
npm run dev
```
